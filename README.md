🏥 Tech Challenge Fase 4 — Modelo Preditivo de Obesidade

Projeto desenvolvido como parte do Tech Challenge Fase 4 da Pós-Tech em Data Analytics da FIAP.

Objetivo

Desenvolver um modelo de Machine Learning para auxiliar equipes médicas a prever o nível de obesidade de um paciente com base em hábitos alimentares, atividade física e histórico familiar.

Resultado

O modelo final é um Voting Classifier combinando Random Forest, CatBoost e LightGBM, atingindo 81.8% de acurácia e AUC de 0.9642 na classificação de 7 níveis de obesidade.

Aplicação

A aplicação foi desenvolvida com Streamlit e conta com duas páginas:

Simulador — preencha os dados do paciente e obtenha a previsão do nível de obesidade com a confiabilidade associada

Dashboard — visão analítica dos dados com gráficos interativos e desempenho do modelo
